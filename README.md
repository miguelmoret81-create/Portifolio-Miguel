# Portfólio - Miguel Moret Toledo Silveira

Bem-vindo ao repositório do meu portfólio profissional. Este projeto foi desenvolvido como parte da avaliação da disciplina de Desenvolvimento Front-end.

**Acesse o site ao vivo:** https://miguelmoret81-create.github.io/Portifolio-Miguel/
## Sobre o Projeto

Este é um site portfólio de página única (one-page) focado em apresentar minhas habilidades, formação acadêmica e projetos. O grande destaque é a integração em tempo real com a API do GitHub, que busca e exibe meus repositórios públicos dinamicamente através de requisições assíncronas.

O design foi construído pensando no meu foco de carreira (Web & Application Security), utilizando um tema Dark Mode com detalhes em verde neon.

## Funcionalidades

- Design responsivo (adaptável para celulares e desktops).
- Integração com a API do GitHub para listagem automática de repositórios.
- Seção com os principais projetos acadêmicos e profissionais.
- Botão para download do currículo em PDF.
- Links diretos para contato via E-mail, LinkedIn e WhatsApp.
- Botão flutuante de "Voltar ao topo" com rolagem suave.
- Menu de navegação com destaque dinâmico da seção atual.

## Tecnologias Utilizadas

O projeto foi desenvolvido em Front-end puro, sem o uso de frameworks, garantindo a separação correta de responsabilidades:

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização com variáveis, Flexbox, CSS Grid e animações.
- **JavaScript (ES6+):** Consumo da API REST do GitHub (Fetch API), manipulação do DOM e eventos de scroll.
- **FontAwesome:** Ícones da interface.
- **Google Fonts:** Tipografia (Inter e Fira Code).

## Estrutura de Pastas

A arquitetura do projeto foi organizada visando as boas práticas de separação de arquivos:

```text
Portifolio-Miguel/
├── css/
│   └── style.css
├── js/
│   └── script.js
├── index.html

```
Como Executar Localmente

1- Clone este repositório:
```
git clone https://github.com/miguelmoret81-create/Portifolio-Miguel.git
```
2- Navegue até a pasta do projeto.

3- Abra o arquivo index.html em qualquer navegador web ou utilize a extensão Live Server no VS Code.
